LA Crime Hotspot Prediction & Anomaly Detection (2020–2023)

Project Overview

Built an end-to-end machine learning system to predict hourly crime hotspots across Los Angeles policing districts using over 1M historical crime records.

Key Features & Achievements

  • Engineered temporal, spatial, lag-based, weather, and demographic features and formulated hotspot detection as a supervised binary classification problem
  • Automated the full ML lifecycle using AWS SageMaker Pipelines, including preprocessing, feature engineering, training, evaluation, and model registration
  • The best-performing XGBoost model (with SMOTE and threshold tuning) achieved 93% accuracy with a balanced hotspot F1-score of 50%
  • Enables proactive resource allocation and improved public safety planning for law enforcement agencies
  • Implemented anomaly detection algorithms to identify unusual crime patterns and emerging hotspots

Technology Stack

Technologies: Python, SQL, AWS SageMaker, S3, XGBoost, Random Forest, TensorFlow/Keras, Scikit-learn, SMOTE, Pandas, NumPy, Matplotlib, Seaborn
