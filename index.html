PROJECT OVERVIEW: Carely — AI Companion

            

                
                
                
            

            

                
Problem

                
Elderly users need an accessible, trustworthy conversational companion for daily support; caregivers need timely alerts when risk signals appear—without exposing sensitive PII.

                
Approach

                
Built a privacy-first architecture: multi-layer memory (short, long, episodic, profile), strict PII detection/redaction, FastAPI services for reminders and detection, Streamlit UI with voice/text, Telegram notifications for emergencies, and pilot-driven iteration.

PROJECT OVERVIEW: LA Crime Hotspot Prediction

            

                
                
            

            

                
Problem

                
Law enforcement and analysts need early warning of high-risk crime hotspots across districts and time windows, using over 1M historical records without manual ad-hoc modeling.

                
Approach

                
End-to-end ML: rich feature engineering (temporal, spatial, lag, weather, demographics), class imbalance handling (SMOTE), model comparison, and SageMaker Pipelines for repeatable training and deployment. Added anomaly detection for unusual patterns.

                
Tech Stack

                
Python, SQL, AWS SageMaker, S3, XGBoost, Random Forest, TensorFlow/Keras, Scikit-learn, SMOTE

                
Impact

                
    
                    
  • 93% accuracy with XGBoost; pragmatic F1 tradeoffs documented for hotspot class.
    • 
                    
  • Shows you can own the full lifecycle on real-scale tabular data—not notebook-only experiments.
